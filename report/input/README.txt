==========================================================
연기금 일일 리포트 - 수동 CSV 다운로드 가이드
==========================================================

이 폴더에 KRX 에서 받은 CSV 를 떨궈주면 build_report.bat 가
자동으로 import + HTML 리포트 생성합니다.

----------------------------------------------------------
[다운로드 절차]  매일 장 마감 후 (15:30 이후, 권장 18:10 이후)
----------------------------------------------------------

1. 브라우저로 접속:
   http://data.krx.co.kr/contents/MDC/MDI/mdiLoader/index.cmd?menuId=MDC0201020403

   (KRX 정보데이터시스템 → 통계 → 주식 → 투자자 →
    투자자별 순매수상위종목)

2. 화면 우측 필터 설정:
   - 시장구분    : 유가증권
   - 투자자구분  : 연기금
   - 거래량/거래대금 : 거래대금
   - 매매구분    : 순매수
   - 조회일자    : 오늘 (또는 보고싶은 영업일)
   → 조회 버튼

3. 표 우측 상단 다운로드 아이콘 (📥) 클릭 → CSV 선택
   → 파일 저장됨 (예: data_2026...

4. 파일을 이 폴더로 복사 + 파일명 변경:
   krx_YYYYMMDD_KOSPI.csv

   예) krx_20260512_KOSPI.csv

5. KOSDAQ 도 같은 식으로:
   - 위 페이지에서 시장구분 → 코스닥 → 조회 → 다운로드
   - 파일명: krx_YYYYMMDD_KOSDAQ.csv

----------------------------------------------------------
[리포트 빌드]
----------------------------------------------------------

cmd 창에서:
  cd /d "E:\1.총무\★개인\연기금-자동매매"
  build_report.bat YYYYMMDD

또는 인자 없이:
  build_report.bat

→ 직전 영업일 기준으로 빌드.
→ 끝나면 브라우저로 report\output\index.html 자동 오픈.

----------------------------------------------------------
[파일명 인식 규칙]
----------------------------------------------------------

generate.py 는 파일명에 다음 키워드가 있으면 자동 매칭:

 - 날짜: YYYYMMDD 8자리 (예: 20260512)
 - 시장: KOSPI / KOSDAQ / KONEX / ALL / 전체 / STK / KSQ / KNX

대소문자 무관. 따라서 아래 형식 다 인식됨:
 - krx_20260512_kospi.csv
 - 20260512-KOSPI-pension.csv
 - kospi_20260512.csv
 - data_20260512_KOSDAQ_연기금.csv
